# Student Performance Prediction System

## Project Description
The Student Performance Prediction System is a machine learning project that predicts student performance based on study hours, attendance, previous marks, assignment scores, and internal assessment scores.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest Classifier
- Streamlit
- Joblib

## Features
- Accepts student academic details as input.
- Predicts student performance as Poor, Average, or Good.
- Provides a simple and interactive web interface.
- Uses a trained machine learning model for predictions.

## How to Run Locally
1. Clone the repository:
   `git clone https://github.com/Sukeerthi-01/student-performance-prediction.git`
2. Open the project folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run the application:
   `streamlit run app.py`

## Machine Learning Model
The project uses a Random Forest Classifier trained on student academic data. The model predicts one of three performance categories: Poor, Average, or Good.
